This folder contains tutorials and examples for building agentic systems with Llama models.

### Multi-Agent Workflow Tutorial

The new Multi-Agent Workflow tutorial teaches you how to:

- **Design specialized agents** with distinct roles (Researcher, Critic, Writer)
- **Define tool schemas** for each agent's capabilities
- **Build an orchestration layer** for agent communication
- **Execute complex workflows** combining multiple agents
- **Apply advanced patterns**: parallel execution, debate patterns, chain patterns

Use case: A Research Assistant system where agents collaborate to research, evaluate, and synthesize information into polished reports.
